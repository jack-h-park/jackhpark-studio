# Support

This is a personal portfolio project, not a hosted support service.

- For reproducible bugs, open an issue using the bug template.
- For feature ideas, explain the user problem and proposed behavior.
- For security issues, follow [SECURITY.md](./SECURITY.md) instead of opening a
  public issue.
- Questions that require private Notion content, production credentials, or
  access to the author's infrastructure cannot be reproduced from this
  repository.
