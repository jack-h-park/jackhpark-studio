# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email
`security@jackhpark.com` with the affected version, reproduction steps, and
any relevant logs or screenshots. We will acknowledge reports within five
business days and coordinate a fix and disclosure timeline with the reporter.

This repository contains deployment configuration and integrations with
third-party services. Never include API keys, OAuth secrets, service-role
credentials, or private Notion content in an issue or pull request.

## Supported versions

Only the latest commit on `main` is actively maintained. Older commits are
provided for historical reference and may contain known issues.
